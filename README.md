# Proyecto Intermodular DAM 
En el presente repositorio se aplicarán los diferentes cambios sobre el proyecto intermodular
de Desarrollo de Aplicaciones Multiplataforma.

Consta de una aplicación llamada OmniFit que se dedicará principalmente al reconocimiento
mediante una inteligencia artificial del rango de movimiento de una persona en el entrenamiento
para corregir la postura entrenando.

* La aplicación será diseñada con Flutter/Dart
